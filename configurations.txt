1. ctrl + ` to open terminal

2. assuming npm is our main project folder

3. install npm globally by typing in the terminal:
  npm i nodemon -g
  cd npm (or where index.js file is located)
  nodemon index.js
  Ctrl+C (exit)

  npm init
  (input info)
  info: after it, it will auto generate package.json from the info inputted then this file 
  package.json is important because this is what npm reads to know what packages to install for your project

4. npm i date-fns (adding dependency)

5. git init

5. add .gitignore file then add node_modules

6. npm install (going to read to package.json and install the node_modules)

7. edited index.js
